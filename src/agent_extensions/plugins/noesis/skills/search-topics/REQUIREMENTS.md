# Specification: Agentic Hierarchical Search Skill for Claude Code CLI

## Overview and Objective

Goal: Implement an autonomous search skill using the Claude Code CLI to find the most relevant topics ("sweet spots") within a deeply nested, hierarchical JSON knowledge base.
Context: The data originates from messy conversation transcripts. Keyword search is insufficient; semantic evaluation is required.
Constraints: * No external API calls allowed.

- All LLM reasoning must be performed natively by the Claude Code CLI.
- Data access must be done locally via temporary files generated by TypeScript helper scripts.

## Core Architecture

The solution relies on an Agentic Tree Traversal loop. Claude acts as a hierarchical navigator, executing local TS scripts to peek at nodes, evaluate their semantic relevance, and decide whether to drill down, step back, or extract the final data.

### The "Goldilocks" & "Peek and Retreat" Logic

The agent evaluates the short_summary of topics against the user's query:

- Too Broad: The topic encompasses the query but is too high-level → Drill Down.
- Too Narrow: The topic covers only a fraction of the intent → Step Back / Look Laterally.
- Worse Fit (The Retreat): Subtopics are fragmented tangents or collectively worse than the parent → Abort Drill Down, Revert to Parent.
- Just Right (Sweet Spot): The node comprehensively covers the intent → Extract Long Summary.

## System Components & Implementation Hints

### Component A: TypeScript Helper Tools

Two lightweight, local TS scripts must be created. The Claude Code CLI will execute these via bun and pipe their output to a temporary markdown file for reading.
**Tool 1: explore_tree.ts**

- Purpose: Allows the agent to "peek" at the immediate children of a specific node.
- Input Arguments: 1. dataPath: Path to the JSON file. 2. targetPath: Pipe-delimited string representing the path (e.g., "Topic|SubTopic"). An empty string "" represents the root.
- Implementation Hints:
  - Parse the target path and traverse the JSON tree to find the target node. 
  - Map the subtopics array of the target node.
  - Output Format: Print a clean JSON string to stdout containing ONLY name, short_summary, and a boolean has_subtopics for the immediate children. Do not print long_summary or deep children to protect the LLM context window.

**Tool 2: read_node.ts**

- Purpose: Fetches the comprehensive data once the "sweet spot" is identified. 
- Input Arguments: Same as Tool 1 (dataPath, targetPath). 
- Implementation Hints:
  - Find the exact node specified by the path. 
  - Output Format: Print the exact path and the full long_summary to stdout.

### Component B: The Agentic Prompt (Standard Operating Procedure)

A system prompt or markdown instruction file must be provided to Claude Code to initiate the loop.

- Implementation Hints for the Prompt:
  - Explicitly instruct Claude to pipe script outputs to tmp_search.md and read the file. 
  - Define the exact execution loop:
    - Start at root: npx tsx explore_tree.ts data.json "" > tmp_search.md 
    - Read tmp_search.md. 
    - Semantically evaluate the results. 
    - Apply the Goldilocks Rule and The Retreat Rule (defined in Section 2). 
    - Iterate until 1-3 highly relevant "Sweet Spot" paths are found. 
    - Run read_node.ts on those paths to gather final context. 
    - Synthesize the final answer for the user. 
    - Clean up by deleting tmp_search.md.

## Execution Flow Example (For Agent Context)

- User asks: "What was decided about the database?"
- CLI Agent executes: explore_tree.ts "" > tmp_search.md 
- CLI Agent reads temp file and identifies "Engineering Meeting" as relevant but broad. 
- CLI Agent executes: explore_tree.ts "Engineering Meeting" > tmp_search.md 
- CLI Agent reads temp file and identifies "DB Migration" (Short summary: "Postgres vs Mongo"). 
- CLI Agent executes (Peeking): explore_tree.ts "Engineering Meeting|DB Migration" > tmp_search.md 
- CLI Agent reads temp file and sees subtopics are noisy (e.g., "Microphone issues", "AWS billing"). 
- CLI Agent applies Retreat Rule: Discards subtopics, accepts "Engineering Meeting|DB Migration" as the sweet spot. 
- CLI Agent executes: read_node.ts "Engineering Meeting|DB Migration" > tmp_search.md 
- CLI Agent reads final data and outputs the synthesized answer to the user.
